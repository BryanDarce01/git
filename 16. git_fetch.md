# `git fetch`

Descarga información nueva del repositorio remoto sin tocar los archivos actuales.

- Tenemos nuestro repositorio local

- Un compañero sube cambios a GitHub

- Nuestra copia local ya está desactualizada

Entonces necesitamos traer esa información nueva.

Ahí entra:

``` bash

git fetch

```

## Git

- Se conecta al remoto `(origin)`

- Descarga commits nuevos

 - Actualiza las referencias remotas

- Pero no mezcla nada con nuestra rama actual

**Trae información sin arruinar mi working directory**

Es como decir:

- “Solo quiero ver qué hay nuevo.”

Esto es seguro.

- No toca nuestro trabajo.
